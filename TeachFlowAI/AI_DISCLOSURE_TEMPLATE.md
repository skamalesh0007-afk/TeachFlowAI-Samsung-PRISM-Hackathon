3. Purpose of AI Usage (Brief Details)

Idea generation / brainstorming:
AI was used to brainstorm the concept of teachable voice automation, workflow learning, accessibility based UI automation, and possible user interaction flows.

Code generation or assistance:
AI was used to assist with Kotlin and Android code, including AccessibilityService implementation, workflow and action models, UI components, semantic matching logic, and code corrections.

UI / UX design:
AI was used to suggest the structure and user flow of the TeachFlow AI interface, including teaching, stopping, replaying, command input, and accessibility service status.

Content creation:
AI was used to assist in preparing project documentation, descriptions, README content, and technical explanations.

Data analysis:
Not applicable. No external dataset based data analysis was a core part of this project.

Testing / debugging:
AI was used to help identify and resolve compilation errors, Kotlin syntax errors, Android AccessibilityService issues, and workflow replay problems during development.

Other:
AI was used as a development assistant for understanding Android APIs, improving implementation approaches, and troubleshooting development issues.
